세계 명소대백과 NEW 41 V1.36 · 41개국 공통 사진검색 보강

- V1.35에서 사진 후보가 확보된 검색 경로를 41개국 모두의 부족한 명소에 확대.
- 기존 15개국의 기본 검색 순서는 유지하고, 결과가 부족한 경우에만 추가 지역·자료원·파일명 검색 실행.
- 기존 26개국에도 동일한 추가 검색과 API 원본검사를 적용.
- 이미 사진 30장인 명소는 자동보강에서 건너뜀. 부족한 명소부터 재보강.
- 저작권 및 명소 일치 검증 우회 없음. 기존 저장 사진/대표사진/순서/설명은 건드리지 않음.
- 앱이 열려 있을 때만 사진 자동보강 작동. 아이패드의 실제 검색 결과는 별도 확인 필요.
