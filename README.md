세계 명소대백과 NEW 41 V1.30 진단 보강판

V1.27의 검색 및 사진 보관 기능을 유지하고, 자동보강이 사진 0장을 저장한 원인이 검색 후보 없음인지 자동선정 후보 없음인지 구분해 결과 보기에 기록합니다. 실제 사진 탐색 성공률 향상은 보장하지 않습니다. 기존 사진은 포함하지 않으며 앱 내부 저장을 유지해야 합니다. 배포 전 전체 사진 백업을 권장합니다.

V1.30 변경: 인도 주요 명소 영어·현지어 검색어, 검색 실패 시 제목 보조검색, 일시적 API 장애에 한정한 1회 재시도, 검색 요청 실패 진단 표시. 기존 사진 보관함·대표사진·순서·설명·삭제복구는 변경하지 않습니다. 실제 iPad 환경 검색 성공률은 현장 테스트가 필요합니다.

V1.30: 검색된 사진 후보는 이용조건 메타데이터가 누락되어도 미리보기에 노출됩니다. 저작권 불확인 후보의 자동 저장은 차단하며, 원본 링크를 통해 확인할 수 있습니다. 재검색 실패 시 이전 후보 보존. 자동보강 실패 사유 세분화. 실제 현장 검색 성능은 테스트 필요.


V1.31: 후보 수집 → 국가/장소 필터 → 이름 연관성 필터 → 최종 후보 → 이용조건 감지의 단계별 집계를 사진여행에 표시. 자동보강 0장 결과에서는 이용조건 미확인, 주소누락, 사진품질/유형 제외, 중복을 구분하여 표시. 자동저장 안전조건을 임의로 완화하지 않으며 기존 사진, 대표사진, 보관자료를 변경하지 않습니다. 주의: 실제 iPad 네트워크 환경에서 사진 검색 회복 여부는 아직 검증되지 않았습니다.
