이미지 자동저장: 위키미디어 이미지 원본/미리보기/Redirect 경로 재시도, 파일 서명 검증, WebP 800px/Q40 변환 확인 후에만 IndexedDB 저장.

실제 iPad/Safari 라이브 서버 CORS 동작은 배포 후 검증해야 합니다. 기존 데이터, 사진 및 IndexedDB 보관함은 삭제하지 않습니다.

V1.7: 신규 아이콘 3종 적용. WebP 인코더 실제 파일 시그니처 진단/OffscreenCanvas 재시도/지원 불가 시 30장 반복 실패 방지.
중요: 해당 iPad Safari 엔진이 WebP 인코딩을 지원하지 않으면 클라이언트 JS만으로 WebP 800/Q40 자동변환 성공을 보장할 수 없습니다. 외부 WASM WebP 인코더 통합은 별도 작업이 필요합니다.

V1.7: Safari native WebP 인코딩 미지원 시 @jsquash/webp 1.5.0(libwebp WebAssembly) 브라우저 ESM 대체 인코더를 시도하고 생성 RIFF/WEBP 시그니처를 확인합니다. 자동사진보강의 인코더 사전 차단을 해제했습니다. 외부 모듈을 불러올 수 없으면 명확한 실패 메시지를 표시하고 반복 저장을 멈춥니다. 이 버전은 CDN 의존이며 오프라인 독립형이 아닙니다. iPad에서 실제 성공은 현장 검증이 필요합니다.

V1.7: 자동 사진 선정 시 그림/그림 촬영/실내/부분사진 메타데이터 제외, 명소 식별 정보가 부족한 후보 자동저장 보류. 메타데이터 필터는 시각적 진위 검증이 아닙니다. 기존 저장 사진은 삭제하지 않습니다.
V1.7: 명소별 사진첩의 "사진 전체 포맷 검사"와 "선택 사진 규격" 추가. IndexedDB 저장 Blob 바이트의 RIFF/WEBP 서명과 실제 이미지 픽셀 크기, 용량을 읽기 전용 확인. 새 변환에는 Q40 설정 기록; 기존 이미지 Q40 여부는 역산 불가.
