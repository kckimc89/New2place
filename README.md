NEW 41 V1.27 — 대표사진 고정 및 명소 삭제(복구 가능)

* 사진첩에서 ⭐ 대표사진 지정하면 이야기 표지에도 지정 사진을 표시합니다. 사진첩 순서와 대표사진 선택은 별도로 보존됩니다.
* 대표사진 선택은 IndexedDB와 기존 백업 설정에 함께 기록합니다.
* 부모모드 > 명소 관리 > 이 명소 삭제 : 목록에서 감추고 사진, 여행기, 검색기억과 대표사진을 보존합니다. 부모모드의 보관된 명소 복구로 되돌릴 수 있습니다.
* 기존 자동검색 및 저장 구조를 변경하지 않았습니다.
* 적용 전 전체 사진 ZIP 백업을 권장합니다.
